Welcome to the **SilentXx Astro Theme** — a modern blog theme for content creators and indie developers.

## Why this theme

Extracted from the SilentXx production site, proven in real-world use:

- 🎨 **Beautiful typography**: Tailwind CSS with light/dark themes
- 🌍 **i18n support**: Chinese and English content, one codebase
- 📑 **Smart TOC**: Built-in SilentXx SmartToc component
- ⚡ **Performance first**: Astro static generation, instant pages

## Quick start

```bash
git clone https://github.com/AheheXx1982/silentxx-astro-theme.git
cd silentxx-astro-theme
npm install
npm run dev
```
