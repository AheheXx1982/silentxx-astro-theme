# 关于这个主题

**SilentXx Astro Theme** 是一个为内容创作者和独立开发者设计的现代化博客主题。

## 主题特点

- **智能目录**：内置 SilentXx SmartToc 组件，五级降级链保证每篇文章都有可用导航
- **双语支持**：中英文内容一套代码，自动切换
- **精美排版**：Tailwind CSS + 暗色/亮色主题

## 快速上手

```bash
npm install
npm run dev
```

## 自定义

- 修改 `src/constants/site-config.ts` 配置站点信息
- 修改 `tailwind.config.mjs` 定制主题色
- 在 `src/content/blog/` 写文章
