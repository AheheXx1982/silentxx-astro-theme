# About This Theme

**SilentXx Astro Theme** is a modern blog theme designed for content creators and indie developers.

## Highlights

- **Smart TOC**: Built-in SilentXx SmartToc component — a 5-level fallback chain gives every article usable navigation
- **i18n**: Chinese and English content in one codebase
- **Beautiful typography**: Tailwind CSS with light/dark themes

## Quick start

```bash
npm install
npm run dev
```

## Customize

- Edit `src/constants/site-config.ts` for site info
- Edit `tailwind.config.mjs` for brand colors
- Write articles in `src/content/blog/`
